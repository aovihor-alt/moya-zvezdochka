# Моя звёздочка 💗

Небольшое Android-приложение для Насти от Тоши.

## Сборка APK через GitHub
1. Создай новый пустой репозиторий на GitHub.
2. Загрузи в него всё содержимое этой папки (не саму ZIP-архивацию).
3. Открой вкладку **Actions** в репозитории.
4. Дождись завершения workflow **Build Android APK**.
5. Внизу успешного запуска открой **Artifacts** и скачай `moya-zvezdochka-apk`.
6. Распакуй архив и установи `app-debug.apk` на Android.

APK собирается автоматически при каждом push в ветку `main`, а также вручную через **Actions → Build Android APK → Run workflow**.

Дата начала отношений задана как 11 октября 2026 года. Счётчик обновляется автоматически. Приложение работает офлайн.
